# 📖 Overview

Finding the right job isn't just about having a resume—it's about having a resume that matches the employer's requirements.

The **AI Job Application Assistant** uses Artificial Intelligence and Natural Language Processing (NLP) to analyze resumes and compare them against job descriptions. It provides actionable insights that help users improve their resumes and prepare for interviews.

This project was built to solve a real-world problem faced by students, fresh graduates, and professionals during the job application process.

---

# ✨ Features

### 📄 Resume Analysis

* Upload resumes in PDF format
* Automatically extract text from resumes
* Extract email addresses

### 🧠 Skill Extraction

* Detect technical skills using NLP
* Identify programming languages
* Extract tools and technologies

### 🎯 Job Matching

* Compare resume with job descriptions
* Calculate Resume Match Score
* Identify missing skills
* Show matching skills

### 💡 Resume Improvement

* Suggest skills to learn
* Highlight improvement areas
* Help optimize resumes for better job matching

### 🎤 Interview Preparation

* Generate interview questions
* Focus on missing technologies
* Help candidates prepare for technical interviews

### 🌐 Interactive Interface

* Clean Streamlit dashboard
* Easy-to-use interface
* Fast resume analysis

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/aminaahsan925/ai-job-application-assistant.git
```

## 2️⃣ Navigate to the Project Folder

```bash
cd ai-job-application-assistant
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run the Application

```bash
streamlit run app.py
```

The application will automatically open in your browser.
